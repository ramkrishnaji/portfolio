# Ramkrishnaji — Portfolio

Next.js 14 (App Router) + Tailwind CSS. Single-page site.

## Run locally
    npm install
    npm run dev        # http://localhost:3000

## Deploy (Vercel)
1. Push this folder to a GitHub repo.
2. Import the repo on vercel.com. No settings needed.
3. Optional: set NEXT_PUBLIC_SITE_URL to your final domain (used for link previews).

## Where to edit
- app/page.jsx: all content (PROFILE, EDUCATION, SKILLS, PROJECTS, ACHIEVEMENTS) sits at the top of the file.
- public/resume.pdf, public/aws.pdf, public/profile.jpg: swap files, keep the names.
